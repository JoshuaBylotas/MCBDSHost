## Service Registration Flow

```
???????????????????????????????????????????????????????????????
?                    Installation                            ?
???????????????????????????????????????????????????????????????

NSIS Installer runs:

1. Extract files to: C:\Program Files\MCBDS API Service\
   ??? MCBDS.WindowsService.exe
   ??? Dependencies (DLLs, .NET runtime)
   ??? appsettings.json
   ??? Binaries/        (empty, for Minecraft server)
   ??? logs/            (empty, for service logs)
   ??? backups/         (empty, for backups)

2. Create registry entries:
   HKLM\Software\MCBDS\API Service\InstallDir = "C:\Program Files..."
   HKLM\...\Uninstall\MCBDS API Service = "..." (for Control Panel)

3. Register Windows Service:
   sc.exe create MCBDSAPIService \
     binPath= "C:\Program Files\MCBDS API Service\MCBDS.WindowsService.exe" \
     start= auto

4. Add Firewall Rule:
   netsh advfirewall firewall add rule \
     name="MCBDS API Service (HTTP)" \
     dir=in \
     action=allow \
     protocol=tcp \
     localport=8080

5. Start Service:
   net start MCBDSAPIService

???????????????????????????????????????????????????????????????
?                    Result                                   ?
???????????????????????????????????????????????????????????????

? Service registered: MCBDSAPIService
? Auto-starts on boot
? Listening on port 8080
? Firewall rule applied
? Accessible at: http://localhost:8080
? Logs available in: C:\Program Files\MCBDS API Service\logs\
```
