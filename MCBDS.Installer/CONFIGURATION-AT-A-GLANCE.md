## Data Storage

```
Different places where settings are stored:

Installation Time:
  ?? Dialog Input
  ?  ?? Port: 9000, Frequency: 60, Max: 20
  ?
  ??? appsettings.user.json
      {
        "Urls": "http://0.0.0.0:9000",
        "Backup": {
          "FrequencyMinutes": 60,
          "MaxBackupsToKeep": 20
        }
      }

  ??? Windows Registry
      HKLM\Software\MCBDS\API Service
      - ServicePort = 9000
      - BackupFrequency = 60
      - MaxBackups = 20

Service Startup:
  ?? Reads appsettings.user.json
  ?? Applies Port 9000
  ?? Configures Backups at 60 min intervals
  ?? Sets max 20 backups
  ??? Running Service with configured settings

Later Modification:
  ?? User edits appsettings.user.json directly
  ?? Restarts service
  ??? Service loads new values
```

## Quick Start Commands

```powershell
# Build the enhanced installer
.\MCBDS.Installer\build-installer.ps1

# Test the installer
.\MCBDS.API.Service.Installer.exe
# (Follow the dialog, enter custom values)

# Verify configuration was created
Get-Content "C:\Program Files\MCBDS API Service\appsettings.user.json" | ConvertFrom-Json

# Check registry
Get-ItemProperty "HKLM:\Software\MCBDS\API Service"

# Verify service running
Get-Service MCBDSAPIService

# Test API endpoint
curl http://localhost:8080/health
```
